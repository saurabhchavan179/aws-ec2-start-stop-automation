AWS EC2 Start/Stop Automation
📌 Project Overview

This project demonstrates the automation of starting and stopping an Amazon EC2 instance using AWS Lambda and Amazon EventBridge.

AWS Lambda functions are used to start and stop the EC2 instance, while EventBridge is used to schedule the automation. AWS IAM provides the required permissions, and AWS CloudTrail is used to monitor API activity.

🛠️ AWS Services Used
Amazon EC2 – Compute instance
AWS Lambda – Start/Stop automation
AWS IAM – Roles and permissions
Amazon EventBridge – Schedule automation
AWS CloudTrail – Monitor API activity

🚀 Project Implementation
1. Create EC2 Instance

Created an Amazon EC2 instance that will be controlled using AWS Lambda.

2. Create IAM Role

Created an IAM role for the Lambda functions with the required permissions to perform EC2 start and stop operations.

3. Create Stop EC2 Lambda Function

Created a Lambda function to stop the EC2 instance.

The function uses the AWS SDK (boto3) to call the EC2 stop_instances API.

4. Test Stop Function

Executed the Lambda function manually and verified the successful stop response.

5. Verify EC2 Instance

Checked the EC2 console and confirmed that the instance changed to the Stopped state.

6. Create Start EC2 Lambda Function

Created another Lambda function to start the EC2 instance.

7. Test Start Function

Executed the Lambda function and verified that the EC2 instance started successfully.

8. Verify Running Instance

Checked the EC2 console and confirmed that the instance changed to the Running state.

9. Configure Amazon EventBridge

Created an EventBridge rule to automatically invoke the Lambda function according to a defined schedule.

10. Schedule EC2 Stop

Configured a scheduled EventBridge rule to invoke the EC2 Stop Lambda function automatically.

11. Verify Scheduled Operation

Verified that the EventBridge schedule triggered the Lambda function and the EC2 instance was stopped successfully.

12. Monitor Using CloudTrail

Used AWS CloudTrail to view and monitor the EC2 API activity generated by the automation.
